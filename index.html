Guardar directamente en GitHub

Opcional. Para actualizar el archivo remoto, utiliza un token de acceso personal con permiso Contents: Read and write sobre el repositorio del usuario.

El token solo permanece en este formulario mientras la página está abierta; no se guarda en el navegador ni se agrega a los archivos. GitHub Pages puede tardar en publicar los cambios después del commit. No compartas enlaces que contengan tokens.

Formato requerido: línea 1 = usuario; línea 2 = config0 o config1; línea 3 = nombre del titular; línea 4 = URL; línea 5 = exactamente 4 palabras separadas por espacios. El archivo usuarios.txt puede contener un usuario por línea (también se aceptan espacios o comas entre identificadores). Las líneas que empiezan por # son comentarios.
